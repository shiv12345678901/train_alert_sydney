Q015 marksL1

Explain the functions of HTTP and DNS.

HTTP (Hypertext Transfer Protocol) is the protocol that allows a web browser and a web server to communicate. When a user opens a website, the browser sends an HTTP request and the server returns a response containing the webpage or other resources. HTTPS is the secure form of HTTP because it encrypts information during transmission.

DNS (Domain Name System) translates human-readable domain names into IP addresses so computers can locate the correct server. For example, DNS helps find the IP address associated with www.example.com, and then HTTP or HTTPS is used to request the page.

Therefore, DNS helps locate the website, while HTTP is used to transfer the requested web content.

Example

Example: When you type www.example.com, DNS resolves its address first; then the browser requests the webpage through HTTPS.

Q025 marksL1

Explain the three goals of information security (CIA triad).

The CIA triad represents three main goals of information security: confidentiality, integrity and availability.

Confidentiality means protecting information from unauthorised access. Passwords, access controls and encryption help ensure that only authorised people can read sensitive data.

Integrity means maintaining the accuracy and completeness of information. Data should not be changed without permission. Checksums and access controls can help detect or prevent unauthorised changes.

Availability means ensuring that authorised users can access information and systems when needed. Backups, reliable networks and system maintenance support availability.

For example, an online banking system must keep customer details private, transaction records accurate and services available to customers.

Q035 marksL1

Differentiate an intranet and an extranet.

An intranet is a private network used within an organisation. It provides employees with access to internal information such as announcements, documents and staff systems. Access is normally restricted to authorised members of that organisation.

An extranet is a controlled extension of an organisation's private network that allows selected external users, such as suppliers, customers or business partners, to access specific information securely.

The main difference is who can use the network: an intranet is mainly for internal staff, whereas an extranet includes approved external users. Both use Internet-related technologies and require appropriate security controls.

For example, a company may use an intranet for employee payslips and an extranet for suppliers to check orders.

Q045 marksL3

Explain the purpose of the alt attribute in an HTML image.

The alt attribute provides alternative text describing an image in an HTML webpage. It is written inside the <img> element.

Its main purpose is accessibility. Screen readers can read suitable alternative text aloud so users who cannot see an image can understand its meaning or function. Alternative text can also appear when an image fails to load.

Good alt text should briefly describe meaningful information in the image rather than repeat unnecessary words. Decorative images that do not convey information can use an empty alt value, alt="", so assistive technology can skip them.

For example, an image of a student using a computer could have the description "Student working on a laptop in a classroom".

HTML / CSS example
<img src="student.jpg" alt="Student working on a laptop in a classroom">

Q055 marksL3

Differentiate relative and absolute hyperlinks.

A hyperlink connects a webpage to another webpage, file or location. HTML uses the <a> element with an href attribute to create a link.

An absolute link contains the complete web address, including the protocol and domain name. It is useful when linking to another website. For example, https://example.com/contact.html is an absolute address.

A relative link identifies a resource based on the location of the current page. It usually does not contain the protocol or domain. For example, contact.html links to a file in the same folder.

Absolute links are generally useful for external websites, while relative links make internal site navigation easier to maintain.

HTML / CSS example
<a href="https://example.com">External website</a>
<a href="contact.html">Contact page</a>

Q065 marksL3

Differentiate ordered and unordered lists in HTML.

HTML provides different list elements to organise related information clearly.

An ordered list, created using <ol>, displays list items in a specific sequence, usually with numbers. It is suitable when the order of items matters, such as instructions for completing a task.

An unordered list, created using <ul>, displays items with bullet markers. It is suitable when the order does not matter, such as a list of services or subjects.

Both types use the <li> element to define each list item. The main difference is that ordered lists show sequence, while unordered lists show a collection of related items.

For example, a registration procedure needs an ordered list, but a list of available courses can use an unordered list.

HTML / CSS example
<ol><li>Open the form</li><li>Submit details</li></ol>
<ul><li>Networking</li><li>Cybersecurity</li></ul>

Q075 marksL2/L3

What is the div element and why should it be used sparingly?

The HTML <div> element is a general-purpose container used to group other elements together. It does not describe the meaning of its content. Developers often use it with CSS classes or IDs to apply styles or create layouts.

However, <div> should be used only when a more meaningful HTML element is not suitable. Using too many generic div elements can make the page harder to understand and maintain. It also provides less information about page structure to assistive technologies.

Whenever possible, developers should use semantic elements such as <header>, <nav>, <main> and <section> because these describe the purpose of the content.

For example, use <nav> for a navigation area instead of a div used only as a navigation wrapper.

Q085 marksL4

Explain the selector, property and value in a CSS rule.

CSS (Cascading Style Sheets) controls the appearance and layout of HTML content. A CSS rule normally consists of a selector and one or more declarations.

A selector identifies the HTML elements to be styled. A property identifies which visual feature will be changed, such as colour or font size. A value specifies the setting applied to that property.

In the rule p { color: blue; }, p is the selector, color is the property and blue is the value. The rule makes the text inside all matching paragraph elements blue.

CSS helps separate presentation from content and makes consistent styling easier across a website.

HTML / CSS example
p {
  color: blue;
  font-size: 16px;
}

Q095 marksL4

Differentiate ID and class selectors in CSS.

CSS uses ID selectors and class selectors to apply styles to specific HTML elements.

An ID selector identifies an element using the id attribute and is written with the # symbol in CSS. An ID should be unique within a webpage. For example, #header can style a particular header element.

A class selector identifies elements using the class attribute and is written with a dot (.). The same class can be applied to many elements. For example, .highlight can style several paragraphs.

The main difference is that IDs are intended for unique elements, while classes are reusable. Classes are generally preferred for styles repeated across a site.

HTML / CSS example
#header { background: navy; }
.highlight { color: red; }

Q105 marksL4

Differentiate block-level and inline elements.

HTML elements can behave as block-level or inline elements when displayed on a webpage.

A block-level element normally starts on a new line and occupies the available horizontal space in its container. Examples include <div>, <p> and <h1>. Block elements are useful for organising major sections of content.

An inline element normally remains within the same line as surrounding text and occupies only the space required by its content. Examples include <span>, <strong> and <a>.

For example, a paragraph appears as a separate block, whereas a hyperlink can appear within a sentence.

CSS can change an element's display behaviour using the display property, so the distinction describes typical default behaviour.

Q115 marksL1

Differentiate a WYSIWYG editor and a text editor.

A WYSIWYG editor stands for What You See Is What You Get. It allows developers to design a webpage visually, with the editing view resembling the final webpage. Users can add text, images and formatting without writing every HTML tag manually.

A text editor is used to write and edit webpage source code directly, including HTML, CSS and JavaScript. It gives developers more precise control over the structure and behaviour of a website, but requires knowledge of the relevant languages.

The main difference is the method of creation: WYSIWYG editors focus on visual editing, while text editors focus on code.

For example, a visual website builder is WYSIWYG, while Visual Studio Code is a code editor.

Q125 marksL5

Explain the three-click rule in website navigation.

The three-click rule is a website usability guideline suggesting that users should be able to find important information within approximately three clicks from the home page.

Its purpose is to encourage simple navigation and prevent visitors from getting lost in a complicated site structure. Clear menus, logical categories and useful internal links help users reach information quickly.

For example, a visitor may follow Home → Courses → Networking to find information about a specific course in two clicks.

The rule is a guideline rather than a strict requirement. A well-organised website may still be easy to use when a task requires more clicks. Clear navigation and user expectations matter more than the number alone.

Q135 marksL5

Explain the four WCAG POUR accessibility principles.

The Web Content Accessibility Guidelines (WCAG) use four main principles, commonly remembered as POUR.

Perceivable: Information must be available in forms users can perceive. For example, images should have meaningful alternative text.

Operable: Users must be able to interact with the website. For example, navigation and controls should work with a keyboard.

Understandable: Content and navigation should be clear and predictable. For example, forms should have clear instructions and error messages.

Robust: Content should work reliably with different browsers and assistive technologies. For example, developers should use valid, semantic HTML.

Together, these principles help make websites usable by people with different abilities and technologies.

Q145 marksL2

Explain the purpose of the HTML main semantic element.

The HTML <main> element identifies the primary content of a webpage. It contains information that is central to the page's main purpose, such as an article, course description or product information.

Using <main> makes the webpage structure more meaningful than using only generic <div> elements. It can also support accessibility by allowing assistive technology users to move directly to the main content instead of navigating through repeated headers and menus.

A webpage should normally have one visible main landmark. Repeated content such as site navigation, logos and footer information should be placed outside the main element.

For example, on a course webpage, the title, course description and subject details belong inside <main>.

HTML / CSS example
<header>College logo</header>
<nav>Home | Courses | Contact</nav>
<main><h1>Bachelor of Networking</h1></main>
<footer>Contact information</footer>

Q164 marksL1

Explain active and passive white space and why designers use them.

White space refers to empty areas of a webpage that improve organisation and readability.

Active white space is intentionally left blank by the designer to direct users' attention to important content. For example, large empty space around an Apply Now button can make it stand out.

Passive white space is the natural spacing between elements such as paragraphs, images and headings. It helps separate different sections of information.

Both types prevent a webpage from appearing crowded. Active white space creates focus, while passive white space improves readability and the visual relationship between content elements.

Q184 marksL7

Explain the four stages of the user-centred design process.

User-centred design focuses on users' needs throughout the development of a multimedia product. A common four-stage workflow includes:

Analysis: Identify users, their needs and project requirements through research.

Design: Plan the structure, content and appearance using ideas, wireframes or mockups.

Implementation: Develop a working prototype based on the planned design.

Deployment: Publish or distribute the product so users can access it.

The process is iterative, meaning designers can use feedback to return to earlier stages and improve the product. For example, after student testing, a team may redesign a confusing navigation menu.

Why is “click here” poor link text?

Link text is the clickable wording of a hyperlink. The phrase “click here” is poor because it does not explain the link's destination or purpose.

Descriptive link text identifies what the user will find after opening the link and improves both navigation and accessibility.

Q234 marksL5

Explain the RCPA principles of visual design, with one example of each.

The RCPA principles are four visual design principles used to improve website appearance and organisation.

Repetition: Repeat fonts, colours or styles to create consistency. For example, use the same navigation style on every page.

Contrast: Create visible differences to highlight important elements. For example, use a dark button on a light background.

Proximity: Place related items close together. For example, keep a form label beside its input field.

Alignment: Arrange elements along a common edge or line. For example, align all headings and paragraphs to the left.

Together, RCPA principles improve clarity, visual balance and readability.

Q244 marksL6

Why should each form label be linked to its input?

An HTML label describes the purpose of an input field. Linking it correctly to its input makes a form more accessible and easier to use.

When a label is associated with an input, screen readers can announce the field's purpose. This helps users understand what information should be entered.

Q254 marksL6

Explain what border-collapse and padding do in table styling.

CSS is used to improve the appearance and readability of HTML tables.

border-collapse controls how borders between neighbouring table cells are displayed. When border-collapse: collapse; is used, adjacent cell borders merge into a single shared border instead of appearing separately. This makes the table look neat and consistent.

padding creates space between the content of a cell and its border. For example, padding: 10px; keeps text from touching the edges and makes table data easier to read.

Therefore, border-collapse improves border appearance, while padding improves internal spacing and readability.

HTML / CSS example
table { border-collapse: collapse; }
th, td { border: 1px solid #ddd; padding: 10px; }

Q264 marksL6

How can Flexbox build a two-column page layout?

Flexbox is a CSS layout method used to arrange webpage elements in rows or columns.

To create a two-column layout, place two elements inside a parent container and apply display: flex; to the container. The child elements then appear side by side by default.

For example, a sidebar can use width: 25%;, while the main content uses width: 75%;. This produces a narrow sidebar and a wider content area.

On smaller screens, a media query can change flex-direction to column so the two sections stack vertically. This helps make the page responsive.

HTML / CSS example
.container { display: flex; gap: 16px; }
.sidebar { width: 25%; }
.content { width: 75%; }
@media (max-width: 600px) {
  .container { flex-direction: column; }
  .sidebar, .content { width: 100%; }
}

Q274 marksL6

What is responsive web design and how do media queries help?

Responsive web design means creating webpages that adapt to different screen sizes, including phones, tablets and desktop computers.

A responsive website uses flexible layouts, appropriately sized images and CSS rules so content remains readable without unnecessary horizontal scrolling.

A media query applies certain CSS styles only when a device or viewport meets a condition. For example, a layout with three columns on a desktop can change into one column when the screen becomes narrow.

Responsive design improves usability because visitors can access the same information comfortably on different devices.

HTML / CSS example
@media (max-width: 600px) {
  .columns { display: block; }
}

Q314 marksL3/L8

Compare GIF, JPEG, PNG and SVG image formats.

Different image formats are appropriate for different multimedia purposes.

GIF supports simple frame-based animation and a limited colour palette, making it useful for simple animated icons.

JPEG supports photographic images with many colours and uses lossy compression to reduce file size.

PNG uses lossless compression and supports transparency, making it useful for screenshots and graphics that require sharp edges.

SVG is a vector format that describes shapes mathematically, so it can scale without becoming pixelated. It is suitable for logos, icons and diagrams.

Choosing an appropriate format helps balance image quality, features and file size.

Q324 marksL3/L8

Differentiate lossy and lossless compression with examples.

Compression reduces the size of a digital file so it takes less storage space and can load or transfer more efficiently.

Lossy compression removes some information permanently to produce smaller files. As a result, repeated editing or strong compression may reduce quality. JPEG photographs are a common example.

Lossless compression reduces file size without permanently removing the original information, allowing the data to be reconstructed exactly. PNG images are a common example.

Lossy compression is suitable when smaller file size is more important than perfect reproduction. Lossless compression is suitable when preserving exact details is important.

Q334 marksL8/Sample

Differentiate raster and vector graphics. Why do resolution and aspect ratio matter?

Raster graphics are made of pixels and are suitable for photographs. When enlarged too much, they may become blurry or pixelated. Examples include JPEG and PNG.

Vector graphics use mathematical paths and shapes. They can be enlarged without losing clarity and are useful for logos and icons. SVG is a common example.

Resolution describes the number of pixels in a raster image and influences how much detail it contains.

Aspect ratio is the relationship between an image's width and height. Keeping the original aspect ratio when resizing prevents stretching or distortion.

Therefore, resolution affects detail, while aspect ratio preserves correct proportions.

Q344 marksL8/Sample

Compare RGB and CMYK colour spaces. Which is suitable for web design?

RGB stands for Red, Green and Blue. It is an additive colour model that combines light to create colours. Computer screens, smartphones and other digital displays use RGB.

CMYK stands for Cyan, Magenta, Yellow and Key (Black). It is a subtractive colour model that uses inks and is mainly associated with printing.

RGB is more suitable for web design because webpages are viewed on digital screens that produce colour with light. CMYK is usually used when preparing printed materials such as brochures and posters.

Therefore, designers normally work with RGB colours for websites and CMYK for print production.

Q354 marksL8

Differentiate aliasing and anti-aliasing in digital images.

Aliasing is the jagged or stair-step appearance of diagonal lines and curved edges in raster graphics. It occurs because smooth shapes are represented by a limited grid of square pixels.

Anti-aliasing is a technique that reduces the appearance of these jagged edges by smoothing the transition between edge pixels and nearby colours.

For example, small diagonal text may look rough without anti-aliasing but smoother with it applied.

Anti-aliasing improves the visual quality of text, shapes and digital images. However, the underlying image resolution still affects the amount of detail that can be shown.

Q364 marksL9

Define animation and explain persistence of vision and frame rate.

Animation creates the appearance of movement by displaying a series of slightly different images, called frames, in sequence.

Persistence of vision is the traditional explanation that an image remains in visual perception briefly after it disappears. In practice, the perception of smooth movement also depends on how the visual system processes changing images.

Frame rate is the number of frames shown each second and is measured in frames per second (fps). For example, 24 fps means 24 frames are displayed in one second.

A suitable frame rate helps make movement appear smooth, while a very low frame rate can make animation look jerky.

Q374 marksL9

Explain keyframes, tweening and interpolation in animation.

A keyframe marks an important state or position of an object at a particular point in an animation.

Tweening is the process of creating intermediate frames between keyframes so an object appears to move or change smoothly.

Interpolation is the mathematical method used to calculate values for those intermediate frames, such as an object's position, rotation or size.

For example, one keyframe may place a ball on the left side of the screen and another on the right. Interpolation calculates positions between them, and the resulting frames create the animation.

These techniques reduce the need to draw or position every frame manually.

Q384 marksL9

Differentiate 2D, 2.5D and 3D animation.

2D animation uses two-dimensional drawings or graphics with width and height. Examples include traditional cartoons and simple moving icons.

2.5D animation uses 2D artwork arranged or manipulated to create an impression of depth, without building every object as a fully three-dimensional model.

3D animation uses digital objects with width, height and depth. Models can be viewed from different angles and animated in a three-dimensional scene.

The main difference is how depth is represented. A flat cartoon is commonly 2D, moving layered images may create a 2.5D effect, and a fully modelled animated character is 3D.

Q394 marksL9

Explain two benefits and two problems of animation on websites.

Animation can improve a website when it supports the content and does not distract users.

One benefit is that animation attracts attention to important changes or actions. Another benefit is that it can demonstrate processes that may be difficult to explain with text alone.

However, excessive animation can distract visitors from important information. Large or unnecessary animation files can also slow loading or affect performance, especially on mobile devices.

For example, a short animation showing how to use a product may be helpful, whereas several continuously moving banners may make the webpage difficult to read.

Designers should use animation only when it adds clear value.

Q404 marksL11

Explain copyright and public-domain material in multimedia.

Copyright is a form of intellectual property protection that gives creators legal rights over original works, including photographs, music, videos and illustrations.

Material found online is not automatically free to copy or reuse. A developer usually needs permission, an appropriate licence or a relevant legal exception before using someone else's copyrighted content.

Public-domain material is not protected by copyright, for example because its copyright has expired. It can generally be reused without seeking copyright permission, although other rights may still matter.

For example, a designer should not assume that an online photograph is free to use simply because it is easy to download.

Q414 marksL11

Explain licences, fair use or fair dealing in multimedia projects.

A licence is permission from a copyright holder to use their work under stated conditions. Some licences permit reuse only with attribution, while others restrict modification or commercial purposes.

Fair use is a legal exception in some countries, particularly the United States, that may allow certain uses without permission after considering several factors.

In Australia, specific fair dealing exceptions apply for purposes such as research or study, criticism or review, and reporting news, subject to legal requirements. There is no general US-style fair use exception.

A commercial website should not assume that copying online photos, music or videos is legal. It should normally use original, licensed or genuinely public-domain material.

Q424 marksL11

What is digital rights management (DRM) and why is it important?

Digital Rights Management (DRM) refers to technologies used to control access to and use of digital content. DRM systems may restrict copying, downloading, printing or playback of protected media.

DRM is used to help copyright owners and distributors manage how digital works are accessed and shared. For example, an online video platform may limit playback to authorised users and devices.

A multimedia designer should respect licensing and access restrictions rather than assume that a playable or downloadable file can be reused freely.

DRM does not replace copyright law, but it is one method of enforcing particular access and usage conditions.

A community sports centre website should be simple, organised and accessible so visitors can quickly find classes, trainers, schedules and contact information.

Q448 marksOfficial sample case 2

A client wants online photographs, background music and a copied promotional clip. Explain copyright, public domain, fair dealing and DRM, then recommend lawful actions.

A multimedia website must use images, music and video legally and ethically. Content appearing on the Internet is not automatically free to copy.

Copyright: Original photographs, music and videos are normally protected by copyright. Reproducing or publishing them without authorisation may infringe the owner's rights, particularly on a commercial website.

Following these steps reduces legal risk and respects creators' intellectual property.

A small business website should help visitors understand the business, find products or services and make contact without confusion.

Q478 marksL3/L8 practice

A company needs a logo, photograph, animated icon and transparent graphic. Choose file formats and explain resizing.

A multimedia designer should choose image formats according to the type of content and how it will be displayed.

Logo: SVG is an appropriate format because it is vector-based. It can be displayed at different sizes without losing sharpness and is useful for icons and brand logos.

Photograph: JPEG is suitable for a detailed digital photograph because it supports many colours and uses lossy compression to reduce file size. The designer should choose a suitable compression level to balance clarity and loading speed.

Animated icon: GIF is suitable for a simple animated icon because it supports frame-based animation, although it has a limited colour palette. Modern alternatives can be considered depending on browser support and project needs.

Transparent graphic: PNG is useful for images requiring transparency and sharp raster detail. It uses lossless compression and suits interface graphics or screenshots.

Resizing: Raster images such as JPEG and PNG contain pixels. Enlarging them beyond their original size may cause blur or pixelation. Vector images such as SVG remain sharp when enlarged because they use mathematical shapes. The designer should maintain the original aspect ratio to prevent distortion.

Using suitable formats, resolution and proportions produces good image quality while keeping file sizes manageable.

Q498 marksL1 security/networking practice

A college IT information website must explain networking and security. Describe HTTP, DNS and the CIA triad using practical examples.

A college IT website should explain how users reach web services and how information is protected.

DNS: The Domain Name System translates readable domain names into IP addresses. When a student enters the college website address, DNS helps the browser locate the correct server.

HTTP and HTTPS: HTTP is used for requests and responses between a browser and a web server. HTTPS is the secure version that encrypts data in transit. A student portal that handles passwords or personal data should use HTTPS.

Confidentiality: Private information should be accessible only to authorised users. Examples include login authentication, correct access permissions and encryption.

Integrity: Information must remain accurate and protected from unauthorised modification. For example, marks and assessment results should be changed only by authorised staff; audit trails and access controls can help.

Availability: Authorised students should be able to reach the portal when needed. Reliable hosting, backups, maintenance and appropriate recovery arrangements support availability.

Practical design: The website should explain these concepts in short paragraphs with meaningful headings and examples, making technical information easier for students to understand.

Together, DNS and HTTPS support web access, while the CIA principles describe core goals for protecting college information.

TOP 015-mark practiceDirect sample question

Differentiate the Internet and the World Wide Web.

The Internet is a worldwide network of interconnected computers and devices that enables communication and the sharing of information. It provides the network infrastructure used by many services.

The World Wide Web (WWW) is a collection of linked webpages and websites stored on web servers. Users access these pages through browsers such as Chrome using web technologies including HTTP or HTTPS.

The main difference is that the Internet is the underlying network, while the World Wide Web is one service that operates over that network. The Internet also supports services such as email and file transfer.

Therefore, the Web is part of the Internet, but they are not the same thing.

Choose image formats for an animated icon and a digital photograph.

Different image formats are appropriate for different purposes because they vary in animation support, image quality and compression.

An animated icon can use GIF (Graphics Interchange Format). GIF supports frame-based animation and simple graphics with a limited colour palette. It is appropriate for small animations, although other modern formats may also be used.

TOP 045-mark practiceDirect sample question

Differentiate inline, embedded and external CSS; recommend one for a multi-page site.

CSS (Cascading Style Sheets) controls webpage appearance, such as colours, typography and layout. It can be added to HTML in three main ways.

Inline CSS is written in an individual element's style attribute and affects that element. Embedded CSS is placed inside a <style> element in the HTML document's <head> and applies to that page. External CSS is stored in a separate .css file and linked from HTML pages.

External CSS is most appropriate for a multi-page website because several pages can share the same stylesheet. This keeps the design consistent and makes maintenance easier. Changing one external CSS file can update all linked pages without editing them separately.

TOP 065-mark practiceAdapted from sample topic

Explain the inverted pyramid writing style and its benefits.

The inverted pyramid is a writing technique in which the most important information appears at the beginning of the content. Supporting facts come next, followed by less important background details.

This approach is useful for websites because many online readers scan pages rather than read every word. One benefit is faster scanning: visitors can identify the main message immediately. Another benefit is better readability: readers can stop early after obtaining essential information.

For example, a college announcement should begin with the exam date and location, followed by instructions and background details.

The inverted pyramid improves communication by helping readers find important information quickly, particularly on mobile devices.

TOP 095-mark practiceAdapted from sample topic

Compare raster and vector graphics, resolution and aspect ratio.

Raster graphics consist of individual pixels and are commonly used for photographs. JPEG and PNG are raster formats. Raster images may become blurry or pixelated when enlarged too much.

Vector graphics use mathematical paths and shapes, so they can be resized without losing sharpness. SVG is a common vector format used for logos and icons.

Resolution describes the amount of pixel detail in a raster image. Enlarging a low-resolution image can reduce its apparent quality.

Aspect ratio is the relationship between an image's width and height. Preserving the original aspect ratio prevents stretching or distortion.

Therefore, image type, resolution and aspect ratio must be considered when preparing graphics for web use.

TOP 105-mark practiceAdapted from sample topic

Compare RGB and CMYK. Which is best for websites?

RGB means Red, Green and Blue. It is an additive colour model in which coloured light is combined to produce other colours. Digital displays such as computer monitors and smartphones use RGB.

CMYK means Cyan, Magenta, Yellow and Key (Black). It is a subtractive colour model used mainly for printing with ink. It is suitable for printed materials such as brochures and magazines.

RGB is more appropriate for website design because webpages are displayed on screens that produce colours using light rather than printing ink. Designers may use CMYK when preparing physical printed versions of their designs.

Therefore, RGB is generally used for digital multimedia, while CMYK is associated with print production.
